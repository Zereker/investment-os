# Alpha Framework

Alpha 是有限的高确信主动风险预算，不是必须花完的仓位。

## 边界

- 合计上限：总组合 15%。
- 持仓数：最多 3–5 只。
- 单只上限：总组合 6%。
- 不使用杠杆，不用短线技术信号建立长期仓位。
- 没有合格机会时，未使用的 Alpha 额度暂时进入 SPY。

## 准入标准

候选必须同时满足：

- 能清楚解释长期商业优势和价值创造机制。
- 有三年以上的投资逻辑与可证伪条件。
- 预期回报明显优于直接持有 SPY/QQQ。
- 最坏情景对总组合的影响可接受。
- 研究信息足够，不属于主题跟随或能力圈外交易。
- 与现有 QQQ 和其他 Alpha 的重复暴露有明确补偿。

## 当前候选（不属于 Constitution）

转型基线暂以 MU 6%、TSM 5%、GOOG 4%作为候选目标。它们不是永久名单；每季度按同一规则审核，可冻结、替换或退出。

## 持仓生命周期

1. 研究：在 Research 目录建立独立 Thesis。
2. 准入：通过 Decision Checklist，记录目标权重和可证伪条件。
3. 持有：季度审核；价格波动不自动改变结论。
4. 冻结：逻辑尚可但权重过高或相对 ETF 优势不足，不再追加。
5. 退出：仅在 Thesis 失效、严重超限、合格替代或税务/账户需要时执行。

## 评价

Alpha 必须同时和 SPY、QQQ及目标 Core 比较。至少使用滚动三年数据，并纳入回撤、税费、时间成本与集中度；单年跑赢不证明可复制能力。
