# Alpha Framework

v3.4 下 Alpha 总硬上限15%，SOXX是唯一授权载体。其他 Alpha 目标与新增授权为0%。

## SOXX规则

- 长期战略上限与最终治理阶段：15%。
- 当前治理阶段上限：6%。
- 3%与4.5%是当前阶段内执行检查点。
- 10%、12.5%、15%是未来治理阶段，必须逐级批准。
- 任何追加都需要完整IC；价格不自动触发交易。
- 未来半导体个股与SOXX共用同一15%预算。

一般单一Alpha 6%上限继续适用于SOXX以外的标的；SOXX由上述逐级例外取代，但不得超过当前阶段或15%总硬上限。

## 生命周期

1. `Research`
2. `Observation`
3. `Approved / Holding`
4. `Approved / Add Candidate`
5. `Frozen`
6. `Exit Review`

SOXX当前为 `Approved / Frozen — DATA GATE`：政策级Thesis已完成，但在实时IBKR与同日穿透数据通过前不得追加。

## 准入与追加

- 三年以上可证伪Thesis；
- 相对SPYM/QQQM的必要性；
- 最坏情景与组合损害；
- 最新同日官方持仓穿透；
- 当前阶段与全部集中度护栏；
- 完整IC `APPROVE`；
- 人工下单。

阶段推进不能与单笔交易在成交后补写批准。
