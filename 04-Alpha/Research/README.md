# 板块倾斜 Research（原 Alpha Research）

> v4.0：SOXX是唯一自主板块倾斜载体，永久硬上限6%；Registry状态见`04-Alpha/Position-Registry.md`。其他候选仅可留在Research，半导体个股必须与SOXX共用同一6%预算。

每个候选建立一个独立文件，文件名使用代码，例如 `SOXX.md`。只有完成研究、通过准入和 IC 的标的才能获得新增资金；新增任何 SOXX 之外的载体还必须先经年度审核修改 Constitution。

- 公司与价值创造机制
- 为什么市场可能定价错误

- 主要风险和反方观点
- 可证伪条件
- 估值区间与预期回报
- 相对 SPYM / QQQM 的机会成本
- 目标权重、最大损失和退出条件
- 下次复核日期

- 费用、跟踪差异、流动性和税务

- 与 SPYM、QQQM 和现有 Alpha 的穿透重叠
