# Alpha Research

每个候选建立一个独立文件，文件名使用代码，例如 `SOXX.md`。只有完成研究、通过准入和 IC 的标的才能升级为 `Approved Alpha` 或获得新增资金。

已有小额真实仓位但研究未完成时，可登记为 `Observation`：全额计入 Alpha 风险预算、允许持有、冻结追加。Observation 不是对既有交易的追认，也不能绕过准入流程。

## 个股必需章节

- 公司与价值创造机制
- 为什么市场可能定价错误
- 三年以上的核心 Thesis
- 关键证据与数据来源
- 主要风险和反方观点
- 可证伪条件
- 估值区间与预期回报
- 相对 SPYM / QQQM 的机会成本
- 目标权重、最大损失和退出条件
- 下次复核日期

## ETF 额外章节

- 指数方法与再平衡机制
- 行业、发行人和前十大持仓集中度
- 费用、跟踪差异、流动性和税务
- 周期性与历史极端回撤
- 与 SPYM、QQQM 和现有 Alpha 的穿透重叠

研究文件不写入 Constitution；候选可以变化，规则保持稳定。历史 Thesis 退出后移入本目录下的 `Archive/`。
