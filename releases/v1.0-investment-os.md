# Investment OS v1.0 Release

## Release Goal

建立第一版完整投资操作系统，将投资决策从经验驱动升级为流程驱动。

## Core Modules

- Investment OS：长期投资原则
- Portfolio Playbook：组合策略
- IBKR Snapshot：账户状态
- Daily Cruise：日常风险检查
- Weekly / Monthly / Quarterly Review：周期复盘
- Decision Scorecard：投资机会评估
- Core Holding Review：核心持仓检查
- Benchmark：与 SPY / QQQ 对比
- Lessons Learned：经验沉淀
