# Investment OS

A personal investment operating system for managing the IBKR portfolio through disciplined decision making.

## Framework

```
Investment OS
      ↓
Portfolio Playbook
      ↓
IBKR Snapshot
      ↓
Review Log
```

## Mission

Through long-term ownership of excellent assets, achieve capital compounding while maintaining controllable risk.

## Core Principles

- Long-term holding beats frequent trading.
- Risk management comes before return seeking.
- Price is a signal, not a decision.
- Fundamentals drive decisions.
- Discipline drives execution.
- Cash is a strategic position.
- Stay within the circle of competence.
- Active trades require a second-opinion review.

## Repository Structure

- `docs/` - Investment OS principles and frameworks
- `playbooks/` - Strategy documents
- `snapshots/` - Portfolio status records
- `reviews/` - Cruise and trade reviews
- `journal/` - Investment lessons learned
