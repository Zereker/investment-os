# Investment OS v6.0 — Three-ETF Daily Brief MVP

## Release Goal

v6.0 把 v5.0 的产品定义推进到可每日使用的最小生产版本。

> 只服务 SPYM、QQQM、SOXX，把已有规则稳定组合成一份确定性的 Daily Brief。

本版本不增加投资标的，不改变目标权重、SOXX 上限、现金规则、回撤档位、资金公式或交易边界。

## Production Universe

新增 `01-Constitution/Investment-Universe.md`，正式冻结当前生产投资宇宙：

- SPYM；
- QQQM；
- SOXX。

其他证券只能作为 Legacy、Out-of-Universe 或 Research 对象出现，不得进入每日新增购买候选。新增第四个标的必须经过 Research、批准、Constitution 修改、执行检查和版本发布。

## Daily Brief Runner

新增 `scripts/daily_brief.py`：

- 从标准输入读取规范化的临时 JSON；
- 不读取或保存券商凭证；
- 不把输入或输出写盘；
- 复用 `monthly_execution.compute`，不复制或发明资金规则；
- 验证 IBKR 四项输入状态和账户核对差异；
- 披露 Out-of-Universe 持仓但不为其生成购买候选；
- 固定输出 Account Health、组合状态、规则含义、候选、Why Not、注意事项和下一观察点；
- 数据缺失或冲突时失败关闭为 `DATA INCOMPLETE`；
- 永不下单，也不生成可直接提交的订单。

运行方式：

```bash
cat /trusted/runtime-state.json | python3 scripts/daily_brief.py
python3 scripts/daily_brief.py --self-test
```

`/trusted/runtime-state.json` 只是运行示意。真实账户数据不得放在仓库目录或提交到 Git。

## Daily Output

Daily Brief 只回答当前三个标的：

1. 今天发生了什么；
2. 当前组合与目标缺口如何；
3. SPYM 回撤处于什么状态；
4. 哪个资金通道获得授权；
5. SPYM、QQQM、SOXX 中谁是候选；
6. 为什么其他标的或其他动作不成立；
7. 下一观察条件是什么。

没有候选时，`HOLD` 是成功结果。

## Validation

CI 新增 Daily Brief 自检，守护以下不变量：

- 封闭三 ETF 投资宇宙；
- 缺失数据失败关闭；
- Out-of-Universe 不产生购买候选；
- Daily Brief 必须包含 Why Not 和 Human Boundary；
- 现有政策一致性与隐私检查继续通过。

## Strategy Impact

无。

v6.0 是运行产品化版本，不是策略升级。所有具体投资参数继续以现行 IPS、Constitution 和 Operating System 为准。
