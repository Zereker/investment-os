# Investment OS v3.2 — Valuation-Aware

发布日期：2026-07-28

## 变更摘要

- Core ETF 从 SPY / QQQ 更新为 SPYM / QQQM。
- 新增估值感知部署框架。
- 将超额现金部署从单一回撤规则升级为三因子规则：Price、Valuation、Liquidity。
- 新增 PE 数据质量闸门，要求记录口径、来源、历史窗口和时间戳。
- 当 PE 数据冲突或无法验证时，只允许正常 DCA，不允许以该数据触发战术加仓。
- 月度流程和 Transition Dashboard 增加 Deployment Dashboard。

## 核心原则

> 价格决定时机，估值决定力度，现金决定规模。

回撤本身不构成充分买入理由。部署金额必须同时受目标缺口、估值水平和剩余现金约束。

## 复杂度说明

本版本用统一 Deployment Framework 替代零散的回撤分档判断，因此虽然增加估值和数据质量维度，但减少了临时判断和重复规则。
