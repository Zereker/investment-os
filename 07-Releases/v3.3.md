# Investment OS v3.3 — Rule Closure

发布日期：2026-07-30

## 定位

v3.3 修复完整策略审计发现的配置、分类、部署和执行冲突。它保留 QQQM 28% 战略成长引擎，不因 ETF 重叠削减成长性，也不产生新的自动买卖指令。

## 配置数学

- Alpha 恢复为 v3.1 已确定的 0%–15%机会预算，没有最低配置要求。
- \(A\) 包含全部实盘 Alpha 与 Observation。
- `SPYM + Alpha = 57%`，因此 `SPYM = 57%−A`。
- 固定 SPYM 42%只是 \(A=15\%\) 的满额端点；\(A=0\%\) 时 SPYM 为 57%。
- QQQM 继续固定为 28%战略成长倾斜。

## SOXX

- SOXX 正式归入 `Alpha / Observation`。
- 全部实时市值计入 Alpha 15%、单只 6%和最多 5 只上限。
- 现有仓位允许持有，追加冻结。
- 升级或追加前必须完成 ETF Thesis、季度审核与完整 IC。
- Observation 身份不追认原买入，也不自动触发卖出。

## 现金部署

- `Routine DCA`：每月计划外部净入金 2,000 美元；实际 Core 买入 \(D=\min(F,G_0)\)，未投入的 \(F-D\) 保留为现金。
- `Strategic Baseline`：按 \(B=\min(S/R,G)\) 计算，既不超过计划月均迁移额，也不超过剩余 Core 正缺口。
- `Tactical Acceleration`：只有可靠价格与估值数据并通过完整 IC 才执行 \(T\)。
- Red / N/A 估值使 \(T=0\)，不阻塞 DCA 与 \(B\)。
- Liquidity 只限制金额，不参与 Opportunity Score。

## 风险与衡量

- 新增科技 45% / 50%、半导体 15%、单一发行人 8% / 10%穿透集中度软护栏。
- 软护栏只预警、复核或冻结新增风险，不自动卖出。
- Policy Benchmark 为 `15% Cash + 57% SPYM + 28% QQQM`；现金使用标准化单位收益率 \(I/\bar C^{eligible}\)，不直接使用实际利息美元。
- Alpha 的增量价值相对其所替代的等额 SPYM 评价。

## 生产修复

- 统一现行交易载体为 SPYM / QQQM。
- 删除 MU / TSM / GOOG 的过时“当前候选”基线。
- 建立 Alpha Position Registry 和季度生命周期流程。
- 将冲突的旧 Assistant 模板降级为权威流程链接。
- 明确例行月度路径与完整 Investment Committee 路径的边界。
- 历史 Dashboard 不再冒充当前数据；所有数量和市值由实时 IBKR Positions 提供。
- Data Dictionary 定义可复现的发行人、行业、半导体穿透字段、覆盖率与聚合公式。

## 兼容性

本版本取代 v3.2 LTS 作为当前 Production。v3.2 Release 与历史 Decision 保留用于审计，其中 SPY / QQQ 只允许出现在明确的历史、代理数据或防切换语境。

## 非交易声明

本次发布不授权 SOXX 追加或退出，不要求把 Alpha 填满，也不直接生成 SPYM / QQQM 买单。任何真实交易仍须使用 v3.3 对应的实时数据与交易路径。
