# Investment OS v3.1 Final

## Release Purpose

本版本完成架构冻结前的最后一次一致性修正。

核心变化：

- Alpha 从目标配置改为机会预算（Budget）。
- Transition 从固定 24 个月改为 24–48 个月执行窗口。
- Core、Alpha、Legacy Portfolio 职责进一步分离。
- 明确禁止因价格、新闻或预测进行交易。

## Final Architecture

### Core Portfolio

- Cash: 15% target (12%-18% range)
- QQQ: 28% target
- SPY: Remaining allocation after Cash, QQQ and active Alpha usage

### Alpha Portfolio

- Budget: 0%-15%
- Maximum 5 holdings
- Single position <= 6%
- Not mandatory to fully deploy
- No qualified opportunity means capital remains in Core

### Transition

Execution window:

2026-2028 (24-48 months)

Completion criteria:

- Core allocation within allowed range
- Legacy holdings processed according to rules
- Portfolio enters Maintenance Mode

## Governance

- Monthly: update dashboard and deploy planned contribution
- Quarterly: review Alpha thesis and concentration
- Annual: only normal window for changing permanent rules

## Freeze Statement

Investment OS architecture is frozen after v3.1.

Future changes require:

1. Evidence of structural problem
2. One year of data or major external constraint
3. Decision Log entry
4. New release version

Routine market movement is not a reason to modify the system.
