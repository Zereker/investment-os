# Investment OS v3.0 — Final Architecture

发布日期：2026-07-22

## 主题

从以选股和每日巡航为中心的系统，升级为以资产配置、月度定投和有限 Alpha 为中心的长期财富管理系统。

## 关键变化

- 固定 Cash 15%、SPY 42%、QQQ 28%、Alpha 15%的目标结构。
- Alpha 最多 3–5 只，单只不超过 6%；具体公司不写入 Constitution。
- 固定每月投入 2,000 美元，以新增资金再平衡为默认方式。
- 建立 2026–2028 Transition Mode 与完成后的 Maintenance Mode。
- 把 Daily Cruise、Playbook、重复日历、回撤/恢复雷达和旧评分模板移出当前架构。
- 合并卖出规则、决策检查、月度/季度/年度治理和复杂度规则。
- 旧版 25 个文件完整归档，Archive 不再具有规则效力。

## 兼容性

这是不兼容升级。v1.x 的 Playbook、Daily Cruise、旧风险文件和 Review 日历全部归档，不应再用于新决策。

## 后续运行

- 每月更新 Transition Dashboard 并投入 2,000 美元。
- 每季度审核 Alpha。
- 每年审核 IPS 与 Constitution。
- 架构冻结；除年度审核或重大约束变化外，不再增加永久规则。
