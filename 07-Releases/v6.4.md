# v6.4 — Composable Cross-Harness Skill System

## Summary

This release turns Investment OS into a cross-harness plugin containing a composable skill library rather than one monolithic skill:

```text
router skill
+ reusable domain skills
+ thin harness manifests
+ deterministic infrastructure tests
+ synthetic agent behavior evals
```

## Skills

- `using-investment-os`
- `reconstructing-portfolio-state`
- `enforcing-behavioral-controls`
- `running-daily-review`
- `running-monthly-review`
- `evaluating-transaction-candidates`
- `routing-investment-research`
- `auditing-investment-os`

Each skill has one independently discoverable, reusable, and testable responsibility. Policy parameters remain only in authoritative repository files and deterministic scripts.

## Distribution

- adds Claude Code and Codex plugin manifests;
- distributes the shared `skills/` tree without platform-specific rewrites;
- keeps skill prose vendor-neutral;
- documents clean-session installation and acceptance testing.

## Testing

Investment OS now separates:

- `tests/`: package, manifest, privacy, routing, and deterministic checks;
- `evals/`: synthetic pressure scenarios for actual agent compliance.

Initial behavior scenarios cover manual figures, missing orders, inherited agent approval, repeated intent through rewording, and Research-to-Production bypass.

## Strategy Impact

None. This release does not change the Production universe, allocation targets, funding formulas, drawdown logic, lifecycle rules, data gates, or human-only execution boundary.

## Privacy

No credentials, account identifiers, balances, positions, orders, fills, returns, or personal trading history are added. Tests and evals use synthetic, non-account data only.
