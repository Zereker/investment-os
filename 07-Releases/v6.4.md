# v6.4 — Standard Cross-Harness Skill Distribution

## Summary

This release restructures the Investment OS skill distribution using the same separation proven by mature multi-harness skill projects:

```text
platform-neutral skill core
+ thin harness manifests
+ authoritative repository policy
+ fresh private runtime state
```

## Changes

- refactors `skills/investment-os/SKILL.md` into a concise platform-neutral entrypoint;
- changes the skill description to trigger-oriented `Use when...` wording;
- moves detailed reusable guidance into `references/`;
- adds `.claude-plugin/plugin.json` for Claude Code distribution;
- adds `.codex-plugin/plugin.json` for Codex distribution;
- declares the shared `skills/` directory as the Codex skill source;
- adds cross-harness installation and acceptance-test documentation;
- adds `scripts/check_skill_distribution.py`;
- adds the distribution validator to CI.

## Architecture

Skill prose names actions and constraints, not vendor-specific tool calls. Harness-specific files only deliver the same skill content through each platform's native plugin mechanism.

The repository remains the only policy authority. Broker state remains private and ephemeral. Installing the skill does not grant broker access and does not permit simulated account reviews when required capabilities are missing.

## Strategy Impact

None. This release does not change the Production investment universe, allocation targets, funding formulas, drawdown logic, lifecycle rules, data-quality semantics, or the human-only execution boundary.

## Privacy

No credentials, account identifiers, balances, positions, orders, fills, returns, or personal trading history are added. Distribution and acceptance tests use no real account state.
