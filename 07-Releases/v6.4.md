# v6.4 — Composable Cross-Harness Skill System

## Summary

This release turns Investment OS into a distributable, composable Skill system:

```text
router/bootstrap skill
+ reusable domain skills
+ deterministic repository tools
+ thin harness adapters
+ non-LLM integration tests
+ real-agent behavior eval scenarios
```

## Changes

- replaces the monolithic Skill with `using-investment-os` plus reusable domain Skills;
- adds independent Skills for portfolio reconstruction, drawdown-state validation, behavioral controls, daily review, monthly review, transaction evaluation, Research routing, and system audit;
- adds explicit `REQUIRED SUB-SKILL` routing and dependency validation;
- adds `.claude-plugin/plugin.json` and `.codex-plugin/plugin.json`;
- adds a Claude Code `SessionStart` bootstrap hook;
- adds Claude Code and Codex abstract-action mappings without changing domain Skill prose;
- adds executable plugin tests that run the bootstrap, parse its JSON, discover Skills, validate manifests, and reject dependency cycles;
- adds synthetic behavior scenarios and a real-agent CLI eval runner;
- adds separate installation and clean-session acceptance guides;
- keeps policy parameters in the authoritative repository and live account state outside Git.

## Testing model

`tests/` verifies non-LLM plugin and repository wiring in CI. `evals/` verifies real Agent behavior through synthetic clean-session pressure scenarios. Full real-model sweeps are a manual or scheduled release gate rather than a required PR check.

## Strategy impact

None. This release does not change the Production investment universe, allocation targets, funding formulas, drawdown policy, lifecycle rules, data-quality semantics, or human-only execution boundary.

## Privacy

No credentials, account identifiers, balances, positions, orders, fills, returns, or personal trading history are added. Tests and evals use synthetic prompts only.
