# Investment OS v3.4.2 — Data Gate Operationalization

发布日期：2026-07-30

## 范围

v3.4.2是数据治理可靠性补丁，不改变v3.4战略或v3.4.1规则：SOXX长期硬上限15%、当前治理阶段6%、当前执行上限3%，风险护栏与逐档治理保持不变。

## 变更

- 新增Look-through Evidence Bundle v1.3，固定SPYM / QQQM / SOXX证据结构并绑定账户快照、未失效Candidate与指定交易后情景。
- 每只基金只接受具体产品官方URL和固定原始路径；三家独立解析器从归档XLSX/CSV重建日期与完整底层行，Invesco官方字段由golden fixture覆盖。
- 证券标识使用CUSIP / ISIN / SEDOL优先的带类型ID；占位ticker不能覆盖稳定标识。
- 发行人身份移至独立哈希化注册表并限定为CIK / LEI；Alphabet A/C等多股权类别必须归并，衍生品组件只能引用已注册证券。
- 区分`market_weight`与`exposure_weight`：允许5 bps披露舍入，衍生品必须按名义敞口及经审计底层分解进入风险计算。
- 发行人未知与分类未知分别计算，验证器独立重算覆盖率、科技、半导体及发行人最坏情形上界。
- 账户快照只保存NAV与当前市值；独立Candidate保存账户哈希、SOXX拟议金额、金额上限和失效时间，Packet权重必须等于重算的交易后权重且不超过当前3%执行上限。
- Green要求三只基金`source_as_of`完全一致、100%发行人与分类覆盖，并通过50%科技、15%半导体及10%发行人硬边界。
- CI加入独立故障测试，拒绝原始文件与holdings错配、零敞口`other`、文件角色复用、发行人别名拆分、晚到账户、虚假Candidate、未来Bundle及既有哈希/指标攻击。
- 历史Bundle只增不改；CI比较base SHA并拒绝覆盖、重命名或删除，扫描不存在时失败且没有模板文件名排除。

## 安全边界

验证器通过只表示一个指定交易后情景的穿透证据完整、自洽且满足机器边界。它不会：

- 改变Position Registry；
- 关闭NYSE Semiconductor Index方法证据缺口；
- 创建或延长Add Candidate；
- 取代8%–10%发行人区间的IC治理判断；
- 自动提交任何订单。
