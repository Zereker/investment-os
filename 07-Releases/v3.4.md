# Investment OS v3.4 — SOXX Strategic Alpha

发布日期：2026-07-30

## 定位

v3.4 将 SOXX 从一般 Observation 提升为唯一战略 Alpha 载体，同时保留严格的阶段治理与数据闸门。本版本改变规则，但不产生自动买卖指令。

## 关键决定

- SOXX长期硬上限与最终治理阶段：15%。
- 当前治理阶段上限：6%。
- 3%与4.5%为当前阶段内执行检查点。
- 未来阶段：10%、12.5%、15%，必须逐级季度批准。
- 其他Alpha新增授权为0%；半导体个股与SOXX共用同一预算。
- 风险护栏和Data Gate优先于长期目标，因此15%不保证一定达到。

## 配置数学

\[
A_{basis}=\max(A_{actual},A_{stage}),\qquad
U=\max(A_{stage}-A_{actual},0)
\]

- SPYM目标：`57%-A_basis`
- 物理现金目标：`15%+U`
- QQQM目标：28%

`U`是SOXX当前阶段未完成额度的现金用途标签，不是第五个资产层。若SOXX因上涨超过阶段，使用实际权重计算并冻结新增，目标仍合计100%。

## SOXX状态

- 政策级Thesis已完成。
- Production生命周期：`Approved / Frozen — DATA GATE`。
- 在实时IBKR账户读取和SPYM/QQQM/SOXX同日穿透快照通过前，继续`HOLD — ADD FROZEN`。
- 价格档位只触发复核，不授权订单。

## 风险护栏

- 科技>45% WARN；达到50%且新增会提高暴露时冻结。
- 半导体达到15%时，每笔新增强制IC。
- 单一发行人>8% WARN；达到10%且新增会提高暴露时冻结。
- 未分类暴露可能越线时：`WAIT / DATA INCOMPLETE`。
