# Investment OS v3.5.1 — Valuation Evidence & Funding Permissions Fix

发布日期：2026-08-01

## 范围

本补丁修正v3.5在估值数据不可得时的单边资金偏差。目标配置、Routine DCA与战略现金迁移计划、SOXX 15%长期硬上限、6%当前阶段、3%当前执行上限、持仓生命周期和人工下单边界均不改变。

## 生产级估值证据

只有同时满足以下条件，才可输出正式`CHEAP / FAIR / EXPENSIVE / VERY EXPENSIVE`并影响资金权限：

- 同一ETF或其精确跟踪指数；
- 当前值与历史序列使用同一P/E口径；
- 来源和定义可复现；
- 至少连续5年、60个互不重复的历史月末值；
- 首次启用及来源、口径或指数变化经过正式验证与PR。

官方当前值但无合格历史只能描述当前估值。宽泛板块代理、跨Trailing/Forward口径序列或方法不透明聚合值只能标记`PROXY CAUTION`，不得输出正式四档或改变资金安排。

QQQM的合格降级路径为QQQM自身，其次为同一Nasdaq-100指数的QQ/指数同口径数据；SOXX只接受SOXX自身或NYSE Semiconductor Index同口径数据；SPYM只接受SPYM自身或其精确跟踪指数同口径数据。

## 资金权限

- Routine DCA `D`：按目标正缺口照常执行，不因估值或估值数据缺失关闭。
- 战略基线 `B`：默认按截至2028-12的既定迁移计划执行；只有生产级高质量信号确认`VERY EXPENSIVE`时才可延缓对应标的`B`。
- 战术加速 `T`：只有生产级高质量信号确认`CHEAP`时才可提交完整IC；数据缺失、`PROXY CAUTION`、`FAIR`、`EXPENSIVE`或`VERY EXPENSIVE`均关闭`T`。
- 任何估值等级都不能单独触发卖出。

## 失败处理

估值不可得时输出`N/A / VALUATION UNAVAILABLE`，保留`D/B`并关闭`T`。账户、持仓或订单数据失败仍关闭全部交易路径；SOXX仍受现行Alpha/Data Gate、阶段与执行上限优先约束。
