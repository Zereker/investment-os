# Investment OS v4.0 — 证据驱动的结构修正与简化

发布日期：2026-07-31

## 主题

v4.0 是一次不兼容升级：用实测合并穿透数据修正目标配置的结构性矛盾，让结构性现金真正承担回撤部署职能，把估值从闸门降级为节奏调节器，并大幅削减与决策价值不匹配的验证机器。全部依据见 `Research/2026-07-31-v4-Evidence-and-Proposal.md`。

## 关键变化

1. **SOXX 重述与封顶**：SOXX 由「Alpha」重述为有硬上限的半导体板块倾斜（行业 beta）。永久硬上限 6%；10% / 12.5% / 15% 历史治理阶段作废。执行检查点保留 3%→4.5%→6%。
   - 依据：2026-07 实测,目标 Core（51% SPYM + 28% QQQM）自身含约 18% 半导体、约 40% 信息技术穿透暴露；SOXX=15% 时组合半导体约 31.7%、IT 约 47.4%，在系统自身护栏下不可达。
2. **护栏语义修正**：科技/半导体护栏约束自主倾斜的新增，不阻断 SPYM / QQQM 例行路径（旧字面规则会令每笔 Core DCA 都需 IC）。单一发行人护栏不变（当前最大 NVDA ≈6.7%，未触线）。
3. **回撤部署条款**（新增）：SPYM 相对历史最高收盘回撤 ≥15% / 25% / 35% 时，现金下限分档临时降至 `10% / 8% / 6% + U`，差额部署至 Core 正缺口；每档每轮回撤周期一次，新高重置；不依赖任何估值数据；现金只用后续入金重建。
4. **结构性现金显式化**：15% 现金的预期成本（约 0.45–0.75pp/年、20 年终值约低 9–14%）写入 IPS 作为显式决策，与回撤部署职能绑定；职能长期空转时年度审核必须重议。
5. **估值框架降级**：估值等级只保留两个执行职责——`CHEAP` 是战术加速 `T` 的必要条件、`VERY EXPENSIVE` 暂停对应标的的战略基线 `B`。例行 DCA `D` 与 `B` 不再被估值数据缺失阻塞（根除 BUG-007 死锁类）。等级定义与百分位边界不变。
6. **穿透子系统简化**：删除 Look-through Evidence Bundle 验证器、解析器、对抗测试、历史检查脚本与全部 JSON 契约（约 3,300 行代码 + 5 个模板），以及含真实账户数据的历史 Bundle 快照。替换为 `08-Data/LOOKTHROUGH_CHECK.md` 季度 15 分钟手工核查。护栏阈值全部保留。
7. **影子基准**：新增 SB-1（0% 现金满仓政策组合 67/33）与 SB-2（100% SPYM）月度记录，仅报告；年度审核以此审判现金拖累与系统复杂度净价值。
8. **生命周期简化**：`Observation / Approved / Add Candidate Packet` 机制退役；现行状态为 `Hold / Frozen / Exit Review`，追加閘门为「当季手工核查 + 实时账户 + 完整 IC（当日有效）+ 人工下单」。

## 复杂度账目

- 删除：4 个校验/解析/测试脚本（约 3,300 行）、5 个 JSON 模板、1 个 Bundle 契约文档、历史 Bundle 快照、10%–15% 阶段治理、Add Candidate Packet 机制。
- 新增：回撤部署条款（1 节）、季度手工核查表（1 文档）、影子基准（2 个只报告序列）、Research 证据文档（1 篇）。
- 净效果：显著净删除；月度/季度流程目标用时不变或下降。

## 已知漂移状态

发布时 `A_actual` 约 7.8%，高于 6% 硬上限（市场漂移所致）。按规则处理：冻结新增、不自动卖出；SPYM 目标按 `57%−A_basis=57%−7.8%≈49.2%` 动态计算。该状态在每日巡检中持续披露，由未来季度审核决定是否进入 `Exit Review`（依据卖出规则,不因漂移本身强制卖出）。

## 兼容性

这是不兼容升级。v3.x 的 Alpha 命名、10%–15% 阶段、Bundle 验证器、估值对 `D/B` 的闸门作用全部失效。历史 Release、BUGLOG 与 Decision Log 条目保留用于审计。

## 非交易声明

本发布只更新治理、计算与流程规则，不写入当前价格或估值结论，不授权任何订单。回撤部署条款自发布起生效，但任何部署仍须在触发日按例行检查执行。
