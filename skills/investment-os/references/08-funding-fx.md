# 人民币资金准备与账户内换汇

本文件衔接已在 IBKR 内的投资资金与美元部署，政策范围以宪法为准。
不覆盖银行端跨境购汇，不增加投资标的，不做汇率预测。

## 1. 明确用途

用户可指定某笔已在账户内的 CNH 用于本袖套投资；这只是用途声明。
原币金额与结算事实必须从 IBKR 新鲜余额确认，不能用口述金额替代。
不保存每月额度，不从余额或单独换汇成交推断本月入金 F，不默认把全部 CNH 换成美元。
Daily 发现 CNH 时单独披露；月度资金审核读取本流程。

## 2. 准备换汇

读取新鲜账户、分币种余额、持仓和未完成订单，完成对账及借款检查。
从唯一 CNH 行读取现金和已结算现金，较小值只表示余额上限，不是换汇建议金额。
必须逐笔明确 CNH→USD、源币金额、保留的 CNH、报价方向、金额单位、
预计及最高可接受费用（含费用币种）、可用结算资金、是否有重复换汇或自动换汇。
任何金额连同各币种费用均不得使任何币种现金为负。不得用购买力代替余额。
报价、费用或相关自动化未知时，停止换汇执行，继续不依赖它的美元账户审核。
余额 exchange_rate 不可作为成交报价，也不可用它把 CNH 假定为 USD。

## 3. 能力与执行

先检查宿主实际提供的券商能力。股票、期权或期货下单接口不等于 CASH 换汇能力。
能力未提供时输出 `NOT EXECUTED`，由账户所有者在 IBKR 的货币转换界面检查
具体报价、费用、金额和结算提示后确认；agent 不生成不受支持的换汇订单。
如未来存在可验证的换汇接口，仍按 SKILL.md 的单次授权、提交一次、回读流程。
审批本流程不是对任何具体换汇金额或后续股票购买的授权。最终权限属于账户所有者，
当前会话无法验证其身份。换汇与买入是两个独立操作。

## 4. 换汇后验证

无论人工或工具执行，重新读取 IBKR 原币余额、已结算余额、未完成订单及成交证据。
预计金额、写入应答或人工完成声明均不能证明成交。证据不完整时输出
EXECUTION UNKNOWN 或 DATA INCOMPLETE，不重试、不重复换汇。
只有券商确认的已结算 USD 增量进入月度 C，费用影响以券商最终余额为准。
换汇后的市场、净值与持仓必须重新读取，不沿用换汇前快照计算部署。

## 5. 时间与下一观察条件

可在入金已结算后准备并逐笔确认换汇，不等待汇率信号。换汇不提前购买 ETF。
固定月度执行日使用当时已结算可用 USD；之后到账或结算的资金留到下个固定日。
不补算、不追溯改变本月次数；下一条件明确为 CNH 结算、换汇证据、USD 结算
或下一固定执行日，不写成笼统的“关注汇率”。

## 6. 报告

报告用途确认、源币与结算余额、换汇能力、费用与订单检查、授权范围、执行状态、
换汇后余额和下一观察条件。没有换汇时不将任何 USD 所得写成零或已结算。
真实金额与记录只在私有会话，仓库仅保存规则和模拟测试。

恢复的定投通道需要对应期间的权威外部入金记录。用途声明与换汇回读仅完成资金
准备，不自动满足 F 的证据门；缺失时明确阻碍，不把资金重新归为历史现金绕过门。
