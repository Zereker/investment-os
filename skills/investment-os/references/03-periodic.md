# 周度、季度与年度流程（Periodic Reviews）

本文件是三个周期性复核的唯一权威。投资参数与阈值以 `00-constitution.md` 为准；冲突时以宪法为准。

---

## 第一部分：周度行为检查点

只以**行为模式**为对象回看一周，不重复每日复盘与月度流程各自覆盖的账户、配置与数据检查。不创造交易信号，不修改目标配置。

### A. 行为与执行

- 本周是否有未经过相应交易路径的账户操作
- 是否出现追涨、接飞刀、盘中临时起意或规则漂移
- 固定投入与战略基线是否完全符合月度公式
- 卖出及规则例外是否在下单前完成完整 Investment Committee Packet
- 回撤部署是否严格按档执行
- 实际执行是否与批准的方向、数量、限价和有效期一致
- 多数日子的 `HOLD` 是否被当作有效结果
- 本周新增研究是否保持为独立提案；是否有未发布的研究指标被误写入 Production 输出

### B. 工作项输出

只允许以下工作项：

- `NO ACTION`：系统正常，无额外动作。
- `MONTHLY INPUT`：记录到下次月度流程，不提前交易。
- `IC REVIEW`：存在真实资金候选，进入 `04-committee.md`，尚未授权下单。
- `DATA FIX`：先修复数据或流程，Trade Gate 保持关闭。

每项必须包含负责人、下一次检查条件和截止到哪个治理窗口；没有工作项时明确写 `None`。

---

## 第二部分：季度流程

只处理组合级偏离与风险，不重新设计配置，也不因一次涨跌修改宪法。目标用时 30 分钟。

### 输入

- 实时 IBKR Positions 与账户净值
- 宪法第一部分战略结构表（四个目标与带宽）

### 检查项

1. 现金、SPYM、QQQM 是否位于各自带宽内，SOXX 正缺口是否为 0；连续偏离须记录并列入年度审核。
2. 最大回撤与回撤部署周期状态（各档已执行/可用）。
3. 是否存在 Legacy / Out-of-Universe 持仓，处置进度如何。
4. 本季是否出现规则外操作、未按档执行的部署，或被跳过的月度投入。

超过带宽只要求披露与复核，不自动卖出。

---

## 第三部分：年度审核

正常情况下唯一允许修改 IPS、目标配置和永久规则的窗口。

### 审核内容

- 投资目标、期限、收入稳定性、流动性需求和风险承受能力是否变化。
- 实际组合与目标组合的全年收益、回撤和波动差异。
- QQQM 30% 是否继续实现预期的战略成长倾斜，而非因短期跑输被临时削减。
- SOXX 5% 是否仍是有意的行业配置，而非惯性持有。
- 回撤部署条款的全年触发与执行记录：现金职能是否真实兑现。
- 各标的连续偏离带宽的记录及其原因。
- 月度固定投入节奏和战略现金迁移基线是否仍可持续。
- Transition Mode 是否应结束，或目标完成时间是否需要重估。
- 规则是否重复、含糊或无法执行。

### 修改门槛

修改永久规则必须同时具备：

1. 至少一年的数据或重大外部约束；
2. 明确的问题陈述；
3. 新规则优于旧规则的证据；
4. 对税务、成本和行为风险的评估；
5. 随新 Release 发布，变更理由记录在该次提交与 PR 中。

### 年度输出

- 年度评分：执行、风险、收益、复杂度四项。
- 纪律执行记录：规则外操作、跳过的投入、未按档执行的部署，各自的次数与原因。
- 保留/修改/删除的规则清单。
- 下一年度目标和投入能力。
- 如有规则变化，发布新的次版本或主版本。
