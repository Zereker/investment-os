# Research Sandbox

这里存放尚未进入生产系统的研究、假设、回测和提案。

## 核心边界

`Research/` 中的任何内容：

- 不得直接触发真实账户交易；
- 不得覆盖 `00-IPS/`、`01-Constitution/` 或 `02-Operating-System/`；
- 不得在每日巡检中作为已经生效的规则；
- 只能以“研究观察”或“待验证假设”出现。

## 研究进入生产的最低要求

1. 明确问题和拟改变的现行规则。
2. 固定数据源、指标定义、时间范围和失败条件。
3. 提供支持证据与反对证据。
4. 说明样本外风险、数据偏差、交易成本和税务影响。
5. 给出对现有持仓的过渡方案。
6. 形成正式 Proposal，并由账户所有者明确批准。
7. 通过新的版本发布进入 Production；不得静默修改。

研究可以推翻假设；生产系统必须稳定执行。
