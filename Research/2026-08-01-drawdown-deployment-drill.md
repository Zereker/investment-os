# 回撤部署条款端到端演练：十年真实数据重放

- 日期：2026-08-01
- 性质：机制验证记录，非规则提案。本文不改变任何阈值；若后续要调整档位，须另走正式提案。
- 工具：`scripts/drawdown_drill.py`
- 数据：stockanalysis.com SPYM / SPY 日收盘，2016-08-02 → 2026-07-31，2,513 个交易日（Yellow，聚合源；生产触发须用 IBKR 或官方序列）

## 1. 为什么做这件事

15% 结构性现金的**全部**理由是回撤部署条款（`01-Constitution/Target-Allocation.md`），成本约 0.45–0.75pp/年。但这套机制自 v4.0 写入以来从未执行过——它的第一次真实运行本来会发生在崩盘当中，那是发现状态机缺陷最坏的时机。

## 2. 结论：状态机正确

七项不变量全部成立：

| 不变量 | 结果 |
|---|---|
| 每档每周期最多触发一次 | 通过 |
| 触发时 DD 确实达到该档阈值 | 通过 |
| 同周期内档位由浅到深触发 | 通过 |
| 深档不会跳过浅档单独触发 | 通过 |
| 新 ATH 收盘后全部档位重置 | 通过 |
| 同一序列重放结果一致（确定性） | 通过 |
| 现金下限助手与已授权事件一致 | 通过 |

**SPYM 与 SPY 的定档结果完全一致**——六个触发事件的日期与档位逐一相同。ETF 跟踪差异不影响触发判定，这一点原本不确定。

## 4. 三个值得所有者知道的事实

### 4.1 T3 十年从未触发，COVID 底部差 0.69 个百分点

SPYM 十年最大回撤为 **34.31%**（2020-03-23），T3 的触发线是 35%。也就是说，在过去十年最深的一次崩盘中，最后一档弹药没有解锁。

这**不构成缺陷判定**：T3 本就是为一代人一遇的事件保留的。按公开的历史，2007–2009（约 −57%）与 2000–2002（约 −49%）都会从容触发 T3。但本次演练的数据源最多只回溯十年，**这两次未经本演练验证**，此处仅作背景，不作为证据。

### 4.2 危机弹药的真实规模是 6 个百分点，COVID 级崩盘解锁其中 4 个

常态现金下限是 12%，回撤档把它逐级降到 10% / 8% / 6%。因此回撤条款相对常态路径的**增量**火力是 6pp of NAV；2020 年 T1+T2 触发，实际解锁 12%→8% 共 **4pp**。

这是 15% 现金买到的东西的准确刻度。v4.0 的证据文档曾指出 v3.5 下「现金下限 12% 只允许约 3pp 部署空间，危机弹药叙事名不副实」——v4.0 把它提到了 6pp，本次演练确认该修复在真实数据上成立。

### 4.3 长期熊市中机制会长时间沉默

2022 周期从 2022-01-03 起，直到 **2024-01-19** 才创出新高——超过两年。T2 在 2022-09-30 触发后，剩余 16 个月里两档都处于「本周期已执行」状态，机制不再有任何动作，即使市场仍深度低于 ATH。

这是「每档每周期一次」的设计后果，不是 bug：它防止在下跌途中反复加码。但所有者应当预期：**慢熊里这套机制只响两次，然后安静很久。**

## 5. 本次演练没有验证的部分

演练只覆盖 **价格 → 档位** 这一半逻辑。`02-Operating-System/State-Reconstruction.md` 第 4 步的另一半——判定「本周期各档是否已执行」——依赖三信号交叉（Journal 定性条目 + IBKR 成交记录 + 现金水位自证）与 IBKR 警报指针。那部分无法用价格序列离线验证，**在真实周期跑过之前仍属未验证状态**。

这是当前最大的剩余风险：价格侧现已证明可靠，状态侧尚未。

## 6. 复现方式

```bash
python3 scripts/drawdown_drill.py                 # SPYM 十年重放 + 不变量检查
python3 scripts/drawdown_drill.py --symbol spy    # 指数交叉验证
python3 scripts/drawdown_drill.py --markdown      # 输出可粘贴的记录块
```

脚本在任一不变量失败时返回退出码 1；数据拉取失败时返回 2 并输出 `DATA INCOMPLETE`，不猜测、不沿用旧值。
