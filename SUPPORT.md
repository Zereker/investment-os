# Support

Use [GitHub Issues](https://github.com/Zereker/investment-os/issues) for plugin
installation problems, reproducible defects, and documentation questions.

Include the plugin version, host product, installation source, and exact error.
Never include brokerage credentials, account identifiers, balances, positions,
orders, fills, authorization records, or other private financial information.

Interactive Brokers authentication, account access, broker data, and order
instruction issues should be handled through
[Interactive Brokers Support](https://www.interactivebrokers.com/support).

Security-sensitive reports should not be filed as public issues. Use GitHub's
private vulnerability reporting feature when it is available for this
repository.
