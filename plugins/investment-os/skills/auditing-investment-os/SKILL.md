# Auditing Investment OS

Resolve current default-branch HEAD and inspect the repository's current required checks, authority order, executable mirrors, release records, privacy controls, and skill distribution.

Distinguish policy defects, implementation drift, stale documentation, runtime capability gaps, and unmerged proposals. Do not use private account state unless the audit explicitly requires a controlled runtime test.

Report evidence, severity, affected contract, current Production impact, remediation path, and verification method. An audit finding does not itself change policy or authorize a transaction.
