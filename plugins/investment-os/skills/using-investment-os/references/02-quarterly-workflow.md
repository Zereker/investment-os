# 季度流程

季度审核只处理自主板块倾斜的必要性、穿透集中度和组合级风险，不重新设计 Core，也不因一次涨跌修改 Constitution。目标用时 30 分钟。

## 输入

- 实时 IBKR Positions 与账户净值
- `04-position-registry.md`
- SOXX 倾斜的书面理由与本季度证据变化
- 当季 `08-lookthrough-check.md` 手工核查记录（本流程第一步生成）
- 组合、Policy Benchmark 与两个影子基准（SB-1 / SB-2）的季度及滚动三年数据

## 第一步：穿透手工核查

按 `08-lookthrough-check.md` 完成本季核查并存档快照。核查未完成时，本季度流程不得给出任何倾斜追加相关结论。

## SOXX 必答

1. 当前生命周期（`Hold / Frozen / Exit Review`）是否准确？
2. 持有半导体倾斜的原始理由是否仍成立？哪项证据最可能证明判断错误？
3. 未来三年的预期回报是否仍明显优于直接持有等额 SPYM？
4. 指数方法、集中度、费用、流动性和周期位置是否支持继续持有？
5. 合并穿透后，本倾斜与 QQQM / SPYM 的重复暴露是否仍有明确补偿？
6. `A_actual` 相对 6% 硬上限与当前执行档的状态；漂移超限时确认冻结（不自动卖出）。

## 生命周期输出

只给出一种状态：

- `Hold`：逻辑有效，权重合规或处于漂移冻结。
- `Frozen`：继续持有，但不追加（数据、护栏或研究条件不足）。
- `Exit Review`：触发 Constitution 卖出规则，先记录证据、税务和执行影响，再进入完整 IC。

## 组合级检查

- 实际组合相对 Policy Benchmark 的季度与滚动三年表现；Policy Benchmark 相对 SB-1（现金代价）与 SB-2（系统净价值）的差异。
- SOXX 相对其所替代的等额 SPYM 的表现（含税费与时间成本）。
- 最大回撤与回撤部署周期状态（各档已执行/可用）。
- 合并 IT 是否超过 45% 预警或达到 50% 倾斜冻结线。
- 合并半导体是否达到 15% 倾斜 IC 线（结构性事实：Core 自身约 18%，预期常态触发）。
- 单一发行人是否超过 8% 预警或达到 10% 冻结线。
- 核查数据缺失时冻结倾斜新增，而不是猜测。

若倾斜连续五年在风险、税费和时间成本后跑输等额 SPYM，年度审核应讨论清退倾斜并简化系统。超过护栏只限制新增风险或进入复核，不自动卖出。
