# Strategic Baseline and Drawdown Deployment Framework

> 原则：目标配置决定资金方向和上限；公式决定例行节奏；回撤分档决定危机部署。系统不持有估值判断，也不因价格高低卖出。

本框架用于 Transition Mode 下历史超额现金的迁移与严重回撤时的现金部署。外部入金驱动的 Routine DCA 与战略基线是例行执行；超过基线的部署只有回撤档位一条机械路径。

## 1. 战略现金迁移基线

在每个固定月度执行日，用实时账户数据和本月例行投入计划定义：

- \(A_{actual}\)、\(A_{stage}\)、\(A_{basis}\)、\(U\)：按 `01-target-allocation.md` 的定义与阈值计算，本节不重复推导；
- \(F\)：本月已到账的实际外部净入金，且 \(F\ge0\)；提款或未到账计划额不得计入（计划数额不入库）；
- \(V\)：\(F\) 到账后、交易前的账户净值；
- \(C_0\)：包含 \(F\)、全部例行订单前的投资组合现金；
- \(G_0\)：按QQQM 28%与SPYM \(57\%-A_{basis}\)计算的Routine DCA前正缺口；
- \(D_{max}=\min(F,G_0)\)：Routine DCA上限；\(D\le D_{max}\)是实际买入额，只受正缺口、现金下限与执行检查约束；
- \(C=C_0-D\)：执行 Routine DCA 后的预计现金；
- \(G\)：分配 \(D\) 后 SPYM 与 QQQM 的剩余正缺口合计；
- \(R\)：到 2028-12（含）剩余的月度执行次数，最小为 1；
- \(S=\max(C-(15\%+U)\times V,0)\)：扣除结构性现金与SOXX阶段储备后的战略剩余。

当月战略迁移基线：

\[
B=\min\left(\frac{S}{R},G\right)
\]

每月用最新数据重算，不沿用旧金额。基线必须同时满足：

- 交易后物理现金不低于总组合\(12\%+U\)（回撤部署档生效时按其临时下限）；
- 不使用融资；
- 资金只进入 SPYM / QQQM 正缺口；
- Data Gate、订单冲突和执行检查通过。

`B` 由上式完全决定，没有任何可以暂停它的判断性闸门。v4.2 退役估值子系统后，BUG-007「数据缺失挂起战略迁移」的复发路径由构造消除。

## 2. 回撤部署（Drawdown Deployment）

执行 Constitution 回撤部署条款的操作规程：

1. 每日巡检记录 SPYM 收盘价相对历史最高收盘价的回撤 `DD` 与当前回撤周期状态（各档已执行/未执行）。
2. 触发条件与临时现金下限：

| 档位 | 触发 | 本档释放 | 累计 | 部署后现金 |
|---:|---|---:|---:|---:|
| T1 | `DD ≥ 10%` | 1.50pp of NAV | 1.50pp | 13.5% |
| T2 | `DD ≥ 15%` | 3.00pp | 4.50pp | 10.5% |
| T3 | `DD ≥ 20%` | 4.50pp | 9.00pp | 6.0% |
| T4 | `DD ≥ 25%` | 6.00pp | 15.00pp | **0%** |

本次部署额 = \(\min\bigl(\sum_{j\in K} w_j\times V,\ \max(C-(0\%+U)\times V,0),\ \text{Core 正缺口}\bigr)\)，其中 \(K\) 是本次新触发且本周期未执行的档集合，\(w_j\) 是该档的梯度定额（1.5 / 3 / 4.5 / 6 pp）。

三个上界的含义：**梯度定额**（这是分批的实现）、**绝对下限**（`0+U` 硬停）、**只买正缺口**。四档合计 15pp，把 15% 现金目标全部部署至 `0+U`。**本条款不判断谷底，只按跌幅机械递增部署量**（依据见 [source repository research](https://github.com/Zereker/investment-os/blob/master/Research/2026-08-01-drawdown-tranching.md)）。

梯度 1:2:3:4 把 60% 的弹药压在 T3/T4 这两个价格更好的位置，同时把首笔保持在 1.5pp；等额分配的首笔会是 3.75pp，落在证据显示的最差入场点上。

**`DD` 超过 25% 后没有任何可解锁的档位**：弹药在 T4 打光，`DD` 继续加深不产生新的部署授权，现金停在 `0+U`（v4.6 决定，依据与证伪条件见 [source repository research](https://github.com/Zereker/investment-os/blob/master/Research/2026-08-01-drawdown-four-tier.md)）。此时的正确输出是「弹药已尽，无动作」，**不是**寻找规则例外，**也不是借款加仓**——IPS 的无杠杆原则不变。

3. 每档在同一回撤周期内最多执行一次；SPYM 创出新的历史最高收盘价后周期重置，所有档位恢复可用。
4. 单日可同时满足多档（如跳空进入 `DD≥25%`），按由浅到深顺序逐档执行，但仍受「每档一次」限制。
5. 部署只进入 SPYM / QQQM 正缺口，优先缺口更大者；分批限价执行。
6. 检查项：实时四项 IBKR 数据、无融资、无重复/冲突订单、订单细节明确。部署只由 `DD` 达档触发，不引入任何其他判断项。
7. 每次执行写入 Journal：`DD`、档位、部署额、订单细节、交易后权重与现金。
8. 现金此后仅以外部新增资金逐月重建至 `15%+U`；不得为重建现金卖出持仓，也不得因此暂停 Routine DCA。

本条款不预测底部；到档执行、不到档不执行。继续下跌不追加档外部署，反弹不撤销既定档位纪律。

### 2.1 机制验证状态

`skills/validating-drawdown-state/scripts/drawdown_drill.py` 用 SPYM 十年真实收盘重放本状态机，七项不变量全部成立（记录见源码仓库研究档案）。**已验证**：价格 → 档位判定、每档每周期一次、由浅到深、新高重置、确定性重放。**未验证**：`02-state-reconstruction.md` 第 4 步「本周期各档是否已执行」的三信号交叉重建——它依赖 Journal、IBKR 成交与警报指针，无法离线验证，在真实周期跑过之前保持未验证状态。

首次真实触发时，除按上述步骤执行外，还必须记录状态重建过程本身是否给出了正确档位，作为该半部分的验证证据。

### 2.2 与再平衡的分工

系统有两个「跌了买」的机制，作用域不同，不可混用：

| 机制 | 处理什么 | 触发 | 资金来源 | 频率 |
|---|---|---|---|---|
| 再平衡（\(D\) / \(B\)） | Core 之间的**相对**移动 | 无门槛 | 入金 + 现金下限**以上**的战略剩余 | 每月 |
| 回撤部署 | 广谱市场**绝对**深跌 | SPYM `DD` ≥ 10/15/20/25% | 解锁常态 `12%+U` 下限**以下**的结构性现金 | 每档每周期一次，25% 处打光 |

**判读规则**：某只 Core 单独回撤而 SPYM 未达档时，正确结论是「由再平衡吸收」，**不是**「机制失灵」。此时不得因单一标的跌幅另行创造部署理由——那属于规则例外，须走完整 IC。

触发口径只用 SPYM 的理由见 Constitution 回撤部署节。

## 3. 价格的职责

- 当前价格：计算市值、仓位、缺口和订单数量。
- 历史最高收盘回撤：驱动回撤部署分档；同时辅助限价与分批时点。

v4.2 起系统不再持有任何估值判断。价格不定义贵或便宜，只用于计量、执行与回撤定档；没有任何资金通道以估值等级为条件（依据见 [source repository research](https://github.com/Zereker/investment-os/blob/master/Research/2026-08-01-valuation-subsystem-retirement.md)）。

## 4. Core 内部资金方向

- 按Constitution分别计算QQQM 28%与SPYM `57%−A_basis`的正缺口。
- \(D\)、\(B\) 与回撤部署优先流向正缺口更大的标的；可按缺口比例分配或只买缺口最大的 1–2 项。
- **本框架的三条通道只买 SPYM / QQQM。** SOXX 的**回补至目标**资金只来自 `U`，与本框架并行、互不占用：回撤部署的绝对下限本就含 `+U`，`S` 的定义也已扣除 `(15%+U)`，因此 `U` 从不出现在 \(D\)、\(B\) 或 tranche 的可分配额里。回补的规则见 Constitution「回补至目标 vs 提高倾斜」节与 `04-position-registry.md`。
- **提高倾斜**（推进 `A_execution_cap`）不使用本框架，必须走倾斜治理与完整 IC 流程。

## 5. 执行约束

- 下跌本身不是买入理由；回撤部署的理由是「到档」而不是「预测反弹」。
- 不预测最低点，不一次性满仓——四档梯度阶梯是这条约束的执行机制，不得绕过它把多档合并成一笔判断性下注。
- 弹药在 `DD` 25% 处按设计打光，现金归零。此后继续下跌时**不得**临时创造新档、不得借款——那些都是规则例外，且本次变更已明确不授权。
- 现金归零档的执行约束：下单量必须为整股，且**含佣金在内**交易后现金不得为负；若下单会使现金为负，减量至现金 ≥ 0。归零后的后续费用、汇兑或分红时点差由外部入金补足，不得转为融资借款。
- 波动日优先限价单；市价单仅在流动性充足、点差极小且即时成交确有必要时使用。
- 每次例行执行记录 \(F,V,C_0,G_0,D,C,R,S,G,B\) 和交易后权重。
- 每次回撤部署额外记录 `DD`、档位与周期状态。
- 买入后不因短期反弹追单，也不因继续下跌立即推翻原规则。
