# 长期经验（Journal）

本文件只保留可复用、与具体账户状态无关的长期经验。交易理由、账户事件、授权、持仓、订单、成交和执行结果只存在于当前私有会话与券商记录，不写入仓库。

这些经验来自旧版交易记录和复盘，是跨版本长期有效的知识。

1. 收益主要来自买入后持有，而不是频繁交易。
2. 离开能力圈和追逐主题会增加可避免损失；行业正确不等于公司正确。
3. 价格是检查信号，不是决策结论；基本面与目标配置决定行动。
4. 新增资金再平衡通常优于频繁卖出，但税务不能成为无限容忍集中风险的借口。
5. 现金能提高韧性和行为稳定，但现金目标必须与组合结构匹配；ETF Core 建立后不再需要用超高现金补偿单股风险。
6. 第二意见和书面检查能阻止冲动交易。
7. 系统越简单越容易长期执行；复杂度必须证明其价值。
8. 默认不交易。证据不足时，继续持有或按既定定投流程执行。
9. 板块倾斜的问题不是“会不会涨”，而是“是否值得替代 Core ETF 并占用有限风险预算”。
10. 目标配置是导航，不要求每天精确；落在允许区间内时不操作。
