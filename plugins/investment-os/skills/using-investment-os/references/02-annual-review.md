# 年度审核

年度审核是正常情况下唯一允许修改 IPS、目标配置和永久规则的窗口。

## 审核内容

- 投资目标、期限、收入稳定性、流动性需求和风险承受能力是否变化。
- 实际组合与目标组合的全年收益、回撤和波动差异。
- QQQM 28% 是否继续实现预期的战略成长倾斜，而非因短期跑输被临时削减。
- SOXX相对其所替代的等额、同期SPYM，是否在风险、税费、研究时间和复杂度成本后创造净价值。
- SOXX 6%永久硬上限是否仍兼容整体IPS；不得为完成目标放宽护栏。
- 实际组合相对 `15% Cash + 57% SPYM + 28% QQQM` Policy Benchmark 的时间加权收益与回撤。
- Policy Benchmark 相对影子基准 SB-1（满仓67/33）与 SB-2（100% SPYM）的累计差异：15%现金与系统复杂度是否值回成本。
- 回撤部署条款的全年触发与执行记录：现金职能是否真实兑现。
- 科技、半导体和单一发行人的穿透集中度及软护栏触发记录。
- 月度固定投入节奏和战略现金迁移基线是否仍可持续。
- Transition Mode 是否应结束，或目标完成时间是否需要重估。
- 规则是否重复、含糊或无法执行。

## 修改门槛

修改永久规则必须同时具备：

1. 至少一年的数据或重大外部约束；
2. 明确的问题陈述；
3. 新规则优于旧规则的证据；
4. 对税务、成本和行为风险的评估；
5. Decision Log 记录及新 Release 说明。

科技达到 50%或单一发行人达到 10%的软护栏必须在本窗口形成明确结论：接受并冻结新增风险、调整未来资金方向，或提出符合卖出规则的方案。不得仅因超过软护栏自动卖出。

## 年度输出

- 年度评分：执行、风险、收益、复杂度四项。
- Policy Benchmark 对比、Alpha 净价值及 Transition / Legacy / 超额现金的独立归因。
- 保留/修改/删除的规则清单。
- 下一年度目标和投入能力。
- 如有规则变化，发布新的次版本或主版本。
