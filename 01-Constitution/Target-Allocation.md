# 目标资产配置（Constitution）

## v3.4 定义

\[
A_{actual}=\frac{\text{SOXX 实时市值}}{\text{账户净值}}
\]

\[
A_{stage}=\text{Position Registry 中当前批准的 SOXX 阶段上限}
\]

\[
A_{basis}=\max(A_{actual},A_{stage}),\qquad
U=\max(A_{stage}-A_{actual},0)
\]

其中 `U` 是尚未完成的当前 SOXX 阶段额度。它作为现金中的用途标签保留，不是独立资产层，也不授权交易。

## 目标数学

SPYM、SOXX实际持仓和未完成阶段储备共同构成57%袖套；只有在当前阶段完成时，才简化为`SPYM + Alpha = 57%`。

| 袖套 | 目标 |
|---|---:|
| 结构性现金 | 15% |
| SOXX 阶段储备 | `U` |
| QQQM | 28% |
| SPYM | `57% − A_basis` |
| SOXX / Alpha 实际持仓 | `A_actual` |

在 `A_actual≤A_stage` 时：

\[
15\%+U+28\%+(57\%-A_{stage})+A_{actual}=100\%
\]

若市场上涨使 `A_actual>A_stage`，则 `U=0`、`A_basis=A_actual`，同样合计100%；此时冻结新增并进入复核，不自动卖出。

评估现金区间时，物理现金目标和允许区间分别为 `15%+U`、`12%+U`至`18%+U`。阶段储备不得与现金重复计入。

## SOXX 特别授权

- SOXX 是唯一 Alpha 载体，长期硬上限与最终治理阶段均为总组合15%。
- 当前 `A_stage=6%`。
- 之后的治理检查点为10%、12.5%与15%；每次推进必须在交易前通过季度审核并更新 Registry。
- 6%不再是 SOXX 的永久单只硬上限；它是当前阶段上限。
- 其他单一 Alpha 的一般上限仍为6%，但 v3.4 下其他 Alpha 目标与新增授权均为0%。
- 未来 MU、TSM 或其他半导体个股必须与 SOXX 共用15%总预算，不得新增独立预算。
- 价格触发、回撤或研究完成不自动推进 `A_stage`，也不自动授权买入。

| SOXX治理阶段 | SPYM目标端点 |
|---:|---:|
| 3% | 54% |
| 4.5% | 52.5% |
| 6%（当前上限） | 51% |
| 10% | 47% |
| 12.5% | 44.5% |
| 15% | 42% |

3%与4.5%是当前6%阶段内的执行检查点；10%、12.5%、15%是需要新治理批准的阶段。

## 穿透集中度护栏

使用同日最新官方基金持仓，合并直接持仓与 ETF 内含持仓：

- 信息技术超过45%：`WARN`。
- 信息技术达到或超过50%：冻结任何会进一步增加科技暴露的 SOXX / Alpha；Core维护不受此项单独阻断。
- 半导体及设备达到或超过15%：任何新增半导体暴露必须进行明确 IC 复核。
- 单一发行人超过8%：`WARN`；达到或超过10%：冻结增加该发行人暴露的 Alpha，并列入年度强制审核。
- 数据缺失、过期或未分类暴露可能导致越线时：`WAIT / DATA INCOMPLETE`。
- 护栏触发只限制新增或要求复核，不自动卖出。
- 风险护栏优先于 SOXX 的任何阶段目标；因此15%可能永远不会被执行完成。

## 再平衡与卖出

1. Routine DCA 与战略基线按 `A_basis` 和 `U` 计算，只进入 SPYM / QQQM 正缺口。
2. SOXX 阶段储备不得在 Data Gate 关闭时转投 SPYM，也不得因其存在而强制买入 SOXX。
3. SOXX 追加始终走完整 IC。
4. 卖出仅基于 Thesis 证伪、永久性资本损害、严重硬上限越界、经审核替换或税务/法律/流动性需要。
5. “涨得太高”“跌得太多”、阶段冻结或短期新闻本身不是卖出理由。

目标配置原则上只在年度审核或正式版本发布中修改。
