# 目标资产配置（Constitution）

## 目标

| 资产层 | 标的 | 目标权重 | 允许区间 |
|---|---|---:|---:|
| 流动性 | 现金 | 15% | 12%–18% |
| Core ETF | SPYM | 42% | 39%–45% |
| Core ETF | QQQM | 28% | 25%–31% |
| Alpha | 高确信个股合计 | 15% | 10%–15% |

Alpha 最多 3–5 只；单只目标不得超过总组合 6%。候选与具体权重属于 Alpha 研究和季度决策，不写入 Constitution。

## Core 标的原则

- SPYM 代表广泛美国大盘 Core。
- QQQM 代表纳斯达克 100 成长 Core。
- 不因短期流动性、成交量或品牌熟悉度在 SPY / QQQ 与 SPYM / QQQM 之间频繁切换。
- 只有费用、跟踪质量、税务、账户限制或产品结构发生实质变化时，才允许重新评审 Core 标的。

## 再平衡原则

1. 优先使用每月新增资金和超目标现金补足最大缺口。
2. 落在允许区间内时不为追求小数点精确而交易。
3. Alpha 未满 15% 不代表必须补满；没有合格机会时，缺额暂时进入 SPYM。
4. 只有严重越界、投资逻辑失效或法律/税务需要时才主动卖出。
5. 再平衡应考虑税费、点差和执行成本。
6. 超额现金的战术部署必须通过估值感知部署框架；单纯回撤不构成充分买入理由。

## 卖出规则

卖出仅允许基于以下原因，并写入 Decision Log：

- 投资逻辑被证伪或出现永久性资本损害风险。
- 仓位严重超过上限，且仅靠新增资金无法在合理期限内修复。
- 经完整审核后，以更高质量 Alpha 替换现有 Alpha。
- 税务、流动性、账户或遗产安排需要。

“涨得太高”“跌得太多”或短期新闻本身不是卖出理由。

## 复杂度规则

- 新增一条永久规则时，必须合并或删除至少一条旧规则，或书面说明为何净增加复杂度不可避免。
- 相同目的只保留一个权威文件。
- Archive 中的规则全部失效。
- 目标配置原则上只在年度审核中修改。
