# 目标资产配置（Constitution）

## 目标

定义：

\[
A = \frac{\text{全部实盘 Alpha 市值（含 Observation）}}{\text{账户净值}}
\]

Alpha 是机会预算，不是必须达到的目标。新交易后的 \(A\) 必须在 0%–15%；若仅因市场漂移超过 15%，立即冻结新增并进入复核，但不自动卖出。目标配置为：

| 资产层 / 组合袖套 | 标的 | 目标 | 允许区间 |
|---|---|---:|---:|
| 流动性 | 现金 | 15% | 12%–18% |
| 战略成长 | QQQM | 28% | 25%–31% |
| 市场底仓 + 主动风险 | SPYM + Alpha | 57% | 54%–60% |
| Alpha 子预算 | 个股或主题 ETF；含 Observation | 0%–15% | 硬上限 15% |
| 市场底仓 | SPYM | `57% − A` | 不设独立固定区间 |

总目标始终满足：

\[
15\% + 28\% + (57\%-A) + A = 100\%
\]

Alpha 最多 5 只；单只不得超过总组合 6%。有真实资金的 Observation 按全部市值计入 \(A\)、持仓数和单只上限。候选、生命周期状态和具体权重属于 Alpha 研究与治理，不写死在 Constitution。

## 穿透集中度护栏

使用最近一次通过数据质量闸门的基金官方持仓，合并直接持仓与 ETF 内含持仓：

- 信息技术超过 45%：`WARN`。
- 信息技术达到或超过 50%：冻结任何会进一步增加科技暴露的新 Alpha；例行 SPYM / QQQM Core 维护不受此项单独阻断。
- 半导体及设备达到或超过 15%：任何新增半导体暴露必须进行明确的 IC 复核。
- 单一发行人超过 8%：`WARN`；达到或超过 10%时，冻结增加该发行人暴露的 Alpha，并列入年度强制审核。
- 上述阈值只触发预警、复核或冻结新增，不自动触发卖出。
- 穿透数据缺失或过期时，增加相关主动暴露的提案只能为 `WAIT / DATA INCOMPLETE`；例行 SPYM / QQQM Core 投入可继续。

## Core 标的原则

- SPYM 代表广泛美国大盘市场底仓。
- QQQM 代表 Nasdaq-100 战略成长引擎。28% 是有意的长期成长倾斜，不因其与 SPYM 重叠而机械削减。
- 不因短期流动性、成交量或品牌熟悉度在 SPY / QQQ 与 SPYM / QQQM 之间频繁切换。
- 只有费用、跟踪质量、税务、账户限制或产品结构发生实质变化时，才允许重新评审 Core 标的。

## 再平衡原则

1. 优先使用每月新增资金和已发布的战略现金迁移基线补足最大正缺口。
2. Cash、QQQM 与 `SPYM + Alpha` 袖套落在允许区间内时，不为追求小数点精确而交易。
3. Alpha 未满 15% 不代表必须补满；没有合格机会时，未使用额度自动留在 SPYM。
4. 新增或追加 Alpha 时，按交易后 \(A\) 同步降低 SPYM 目标；退出 Alpha 时，释放额度回到 SPYM。
5. 只有严重越界、投资逻辑失效或法律/税务需要时才主动卖出。
6. 再平衡应考虑税费、点差和执行成本。
7. 战略现金迁移由目标缺口和剩余转型期决定；估值只允许加速，不得把已发布的基线降为零。

## 卖出规则

卖出仅允许基于以下原因，并写入 Decision Log：

- 投资逻辑被证伪或出现永久性资本损害风险。
- 仓位严重超过硬上限，且仅靠新增资金无法在合理期限内修复。
- 经完整审核后，以更高质量 Alpha 替换现有 Alpha。
- 税务、流动性、账户或遗产安排需要。

“涨得太高”“跌得太多”、Observation 身份或短期新闻本身不是卖出理由。

## 复杂度规则

- 新增一条永久规则时，必须合并或删除至少一条旧规则，或书面说明为何净增加复杂度不可避免。
- 相同目的只保留一个权威文件。
- Archive 中的规则全部失效。
- 目标配置原则上只在年度审核中修改。
