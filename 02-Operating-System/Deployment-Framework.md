# Valuation-Aware Deployment Framework

> 原则：价格决定时机，估值决定力度，现金决定规模。

本框架只用于部署超额现金和非例行加仓，不替代每月固定投入，也不用于短线交易。

## 1. Price Score：从近期高点的回撤

| 回撤 | 分数 |
|---:|---:|
| < 5% | 0 |
| 5%–10% | 1 |
| 10%–15% | 2 |
| 15%–20% | 3 |
| > 20% | 4 |

优先使用对应指数或同一指数 ETF 的可验证高点。QQQM 使用 Nasdaq-100 / QQQM 同口径数据；SPYM 使用 S&P 500 / SPYM 同口径数据。

## 2. Valuation Score：PE 历史百分位

| PE 历史百分位 | 分数 |
|---:|---:|
| > 80% | 0 |
| 60%–80% | 1 |
| 40%–60% | 2 |
| 20%–40% | 3 |
| < 20% | 4 |

### 数据质量闸门

PE 数据必须同时记录：

- 指数名称；
- PE 口径：TTM、静态、预测或其他；
- 盈利口径：加权、剔除亏损公司、调和平均等；
- 数据来源；
- 历史窗口，例如 10 年；
- 数据时间戳。

若页面内部 PE 数值冲突、口径不明或来源不可验证，Valuation Score 标记为 `N/A`，不得用猜测值补齐，也不得单独触发交易。

## 3. Liquidity Score：现金比例

| 现金比例 | 分数 |
|---:|---:|
| < 15% | 0 |
| 15%–25% | 1 |
| 25%–35% | 2 |
| 35%–45% | 3 |
| > 45% | 4 |

现金比例按账户净值计算。受限历史仓位不计入现金，但在风险检查中单独披露。

## 4. Deployment Score

总分 = Price Score + Valuation Score + Liquidity Score。

| 总分 | 默认动作 |
|---:|---|
| 0–3 | HOLD，不部署超额现金 |
| 4–5 | 仅正常 DCA 或象征性买入 |
| 6–7 | 第一档，小额部署 |
| 8–9 | 第二档，中等部署 |
| 10–12 | 第三档，显著部署；仍不得一次用尽现金 |

当 Valuation Score 为 `N/A` 时，只允许正常 DCA；除非 Constitution 目标缺口极大且通过书面人工审核，否则不得执行战术加仓。

## 5. Core 内部资金方向

- 分别计算 SPYM 与 QQQM 的 Price Score 和 Valuation Score。
- 在两者均通过数据质量闸门时，新增 Core 资金优先流向估值更低、目标缺口更大的标的。
- 不采用机械 50/50。
- 单次战术部署后，必须保留至少下一档和再下一档的现金能力。

## 6. 执行约束

- 下跌本身不是买入理由。
- 不预测最低点，不一次性满仓。
- 波动日优先限价单；市价单仅在流动性充足、点差极小且即时成交确有必要时使用。
- 每次非例行部署必须记录：数据、评分、金额、订单方式和下一档触发条件。
- 买入后进入观察期，不因短期反弹追单，也不因继续下跌立即推翻原规则。
