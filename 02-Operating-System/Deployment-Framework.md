# Strategic Baseline, Drawdown Deployment and Valuation-Aware Framework

> 原则：目标配置决定资金方向和上限；公式决定例行节奏；回撤分档决定危机部署；估值只影响战术加速与极端等级下的基线；估值贵本身不卖出。

本框架用于 Transition Mode 下历史超额现金的迁移与严重回撤时的现金部署。外部入金驱动的 Routine DCA 与战略基线是例行执行；超过基线的金额属于战术加速或回撤部署。

## 1. 战略现金迁移基线

在每个固定月度执行日，用实时账户数据和本月例行投入计划定义：

- \(A_{actual}\)、\(A_{stage}\)、\(A_{basis}\)、\(U\)：按 `01-Constitution/Target-Allocation.md` 的定义与阈值计算，本节不重复推导；
- \(F\)：本月已到账的实际外部净入金，且 \(F\ge0\)；提款或未到账计划额不得计入（计划数额不入库）；
- \(V\)：\(F\) 到账后、交易前的账户净值；
- \(C_0\)：包含 \(F\)、全部例行订单前的投资组合现金；
- \(G_0\)：按QQQM 28%与SPYM \(57\%-A_{basis}\)计算的Routine DCA前正缺口；
- \(D_{max}=\min(F,G_0)\)：Routine DCA上限；\(D\le D_{max}\)是实际买入额，v4.0 起不被估值等级或估值数据缺失削减；
- \(C=C_0-D\)：执行 Routine DCA 后的预计现金；
- \(G\)：分配 \(D\) 后 SPYM 与 QQQM 的剩余正缺口合计；
- \(R\)：到 2028-12（含）剩余的月度执行次数，最小为 1；
- \(S=\max(C-(15\%+U)\times V,0)\)：扣除结构性现金与SOXX阶段储备后的战略剩余。

当月战略迁移基线：

\[
B=\min\left(\frac{S}{R},G\right)
\]

每月用最新数据重算，不沿用旧金额。基线必须同时满足：

- 交易后物理现金不低于总组合\(12\%+U\)（回撤部署档生效时按其临时下限）；
- 不使用融资；
- 资金只进入 SPYM / QQQM 正缺口；
- Data Gate、订单冲突和执行检查通过。

v4.0 估值职责：`B` 只在对应标的最终等级为 `VERY EXPENSIVE` 时暂停；`CHEAP / FAIR / EXPENSIVE / N/A` 均不阻塞 `B`。估值数据缺失不得挂起战略迁移（BUG-007 防复发）。

## 2. 回撤部署（Drawdown Deployment）

执行 Constitution 回撤部署条款的操作规程：

1. 每日巡检记录 SPYM 收盘价相对历史最高收盘价的回撤 `DD` 与当前回撤周期状态（各档已执行/未执行）。
2. 触发条件与临时现金下限：

| 档位 | 触发 | 临时现金下限 | 部署额 |
|---:|---|---:|---|
| T1 | `DD ≥ 15%` | `10%+U` | \(\max(C-(10\%+U)\times V,0)\)，且不超过 Core 正缺口 |
| T2 | `DD ≥ 25%` | `8%+U` | 同式，下限换 `8%+U` |
| T3 | `DD ≥ 35%` | `6%+U` | 同式，下限换 `6%+U` |

3. 每档在同一回撤周期内最多执行一次；SPYM 创出新的历史最高收盘价后周期重置，所有档位恢复可用。
4. 单日可同时满足多档（如跳空进入 `DD≥25%`），按由浅到深顺序逐档执行，但仍受「每档一次」限制。
5. 部署只进入 SPYM / QQQM 正缺口，优先缺口更大者；分批限价执行。
6. 检查项：实时四项 IBKR 数据、无融资、无重复/冲突订单、订单细节明确。**估值等级与估值数据可得性不是检查项**；回撤部署优先于估值暂停。
7. 每次执行写入 Journal：`DD`、档位、部署额、订单细节、交易后权重与现金。
8. 现金此后仅以外部新增资金逐月重建至 `15%+U`；不得为重建现金卖出持仓，也不得因此暂停 Routine DCA。

本条款不预测底部；到档执行、不到档不执行。继续下跌不追加档外部署，反弹不撤销既定档位纪律。

### 2.1 机制验证状态

`scripts/drawdown_drill.py` 用 SPYM 十年真实收盘重放本状态机，七项不变量全部成立（记录见 `Research/2026-08-01-drawdown-deployment-drill.md`）。**已验证**：价格 → 档位判定、每档每周期一次、由浅到深、新高重置、确定性重放。**未验证**：`State-Reconstruction.md` 第 4 步「本周期各档是否已执行」的三信号交叉重建——它依赖 Journal、IBKR 成交与警报指针，无法离线验证，在真实周期跑过之前保持未验证状态。

首次真实触发时，除按上述步骤执行外，还必须记录状态重建过程本身是否给出了正确档位，作为该半部分的验证证据。

## 3. 价格与估值的职责

- 当前价格：计算市值、仓位、缺口和订单数量。
- 历史最高收盘回撤：驱动回撤部署分档；同时辅助限价与分批时点。
- Forward P/E自身历史百分位：形成`CHEAP / FAIR / EXPENSIVE / VERY EXPENSIVE`基础等级（定义见`ETF-Valuation-Framework.md`）。
- v4.0 起估值等级只承担两个职责：`CHEAP` 是战术加速 `T` 的必要条件；`VERY EXPENSIVE` 暂停该标的的 `B`。

## 4. 估值等级与部署路径

等级到 `D / B / T` 的完整映射表见 `ETF-Valuation-Framework.md` 第 5 节，本节不重复。要点：`D` 从不受估值约束；`B` 只在 `VERY EXPENSIVE` 时暂停该标的；`T` 只有 `CHEAP` 才可提交完整 IC；回撤部署一律按档位规则执行，不受估值等级与估值数据可得性影响。

以上适用于SPYM / QQQM正缺口。SOXX沿用板块倾斜治理、Registry和完整IC路径，估值等级不授权追加。

## 5. Tactical Acceleration

只有相关Core为`CHEAP`、估值数据合格、存在正缺口且完整IC通过时，才允许`T>0`。每次IC单独确定金额；回撤和流动性只参与执行约束。战术加速金额还必须满足：

- 不超过战略剩余 \(S-B\)；
- 不超过执行后仍高于现行现金下限、且保留未来两期基线的金额；
- 不超过执行基线后的 Core 正缺口；
- 不得一次用尽可部署现金。

任何 \(T>0\) 都属于非例行战术加速，必须完成完整 Investment Committee Packet。

## 6. Core 内部资金方向

- 按Constitution分别计算QQQM 28%与SPYM `57%−A_basis`的正缺口。
- \(D\)、\(B\) 与回撤部署优先流向正缺口更大的标的；可按缺口比例分配或只买缺口最大的 1–2 项。
- SOXX / 板块倾斜的新增资金不使用本框架，必须走倾斜治理与完整 IC 流程。

## 7. 执行约束

- 下跌本身不是买入理由；回撤部署的理由是「到档」而不是「预测反弹」。
- 不预测最低点，不一次性满仓。
- 波动日优先限价单；市价单仅在流动性充足、点差极小且即时成交确有必要时使用。
- 每次例行执行记录 \(F,V,C_0,G_0,D,C,R,S,G,B\) 和交易后权重。
- 每次回撤部署额外记录 `DD`、档位与周期状态。
- 买入后不因短期反弹追单，也不因继续下跌立即推翻原规则。
