# 年度审核

年度审核是正常情况下唯一允许修改 IPS、目标配置和永久规则的窗口。

## 审核内容

- 投资目标、期限、收入稳定性、流动性需求和风险承受能力是否变化。
- 实际组合与目标组合的全年收益、回撤和波动差异。
- Alpha 是否在风险、税费和时间成本后创造价值。
- 每月 2,000 美元投入是否仍可持续。
- Transition Mode 是否应结束，或目标完成时间是否需要重估。
- 规则是否重复、含糊或无法执行。

## 修改门槛

修改永久规则必须同时具备：

1. 至少一年的数据或重大外部约束；
2. 明确的问题陈述；
3. 新规则优于旧规则的证据；
4. 对税务、成本和行为风险的评估；
5. Decision Log 记录及新 Release 说明。

## 年度输出

- 年度评分：执行、风险、收益、复杂度四项。
- 保留/修改/删除的规则清单。
- 下一年度目标和投入能力。
- 如有规则变化，发布新的次版本或主版本。
