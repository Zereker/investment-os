# 季度流程

季度审核只处理 Alpha 的必要性和组合级风险，不重新设计 Core。

## 每只 Alpha 必答

1. 原始投资逻辑是否仍成立？
2. 哪项证据最可能证明判断错误？
3. 未来三年的预期回报是否仍明显优于直接持有 SPY/QQQ？
4. 商业质量、资产负债表、竞争优势和估值是否支持继续持有？
5. 与其他 Alpha 和 QQQ 的相关性是否造成重复暴露？
6. 当前权重是否符合单只不超过 6%、Alpha 合计不超过 15%？

## 输出

每只标的只给出一种状态：

- 保留：逻辑有效，权重合理。
- 冻结：继续持有，但不追加。
- 增加候选：逻辑有效且低于目标，允许月度流程补足。
- 退出评审：触发卖出规则，先记录证据和税务影响再执行。

## 组合级检查

- Alpha 相对 Core ETF 的季度与滚动三年表现。
- 最大回撤、集中度、行业重叠和不可补偿风险。
- 研究与管理时间是否值得。
- 若 Alpha 连续五年在风险和费用后跑输目标 Core，则年度审核应讨论降低 Alpha 上限。

季度审核不得因一次涨跌修改 Constitution。
