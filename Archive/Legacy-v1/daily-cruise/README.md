# Daily IBKR Cruise

## Purpose

每日巡航用于风险监控和纪律检查，不用于预测短期市场，也不作为自动交易信号。

核心原则：

> 保护复利系统，而不是追逐每日波动。

## Daily Check

1. 账户健康
- 账户净值变化
- 现金比例
- 杠杆情况
- 当日盈亏

2. 组合异常
- 是否出现重大基本面变化
- 是否有风险事件
- 是否需要进入 Review

3. 核心持仓
- 投资逻辑是否仍然成立
- 是否需要重新评估

4. 纪律检查
- 是否发生情绪交易
- 是否偏离能力圈

## Output

每日巡航只输出三个状态：

- 🟢 无操作
- 🟡 需要关注
- 🔴 需要 Review
