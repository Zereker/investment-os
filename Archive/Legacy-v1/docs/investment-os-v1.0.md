# Investment OS v1.0

## Mission

通过长期持有优秀资产，在可控风险下实现资本复利增长。

## Core Principles

### 1. 长期持有优于频繁交易

默认状态是不交易。只有充分理由才改变长期仓位。

### 2. 风险优先

先回答如果判断错误会发生什么，再考虑收益。

### 3. 价格负责提醒

价格变化只触发分析，不直接触发买卖。

### 4. 基本面负责决策

买入、卖出、继续持有都必须基于基本面判断。

### 5. 纪律负责执行

任何主动交易必须经过标准化 Review。

### 6. 现金也是资产

目标现金比例约35%，最低红线30%。

### 7. 能力圈原则

不研究、不理解的资产不交易。

## Default Rule

没有证据证明交易优于继续持有时，默认继续持有。
